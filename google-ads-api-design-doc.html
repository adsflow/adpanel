1. Company Overview

ScaleAdsFlow is a performance-focused digital marketing agency based in Turkey. We specialize in managing and optimizing Meta (Facebook/Instagram) and Google Ads campaigns on behalf of our clients — small-to-medium businesses across e-commerce, healthcare, real estate, and service industries.

Our agency operates under a Manager Account (MCC ID: 930-696-8254), through which we manage multiple client ad accounts. We have developed an internal campaign management platform — the ScaleAdsFlow AdPanel — to streamline operations, centralize reporting, and improve client transparency.

2. Tool Description — ScaleAdsFlow AdPanel

The ScaleAdsFlow AdPanel is an internal web application built specifically for our agency's operations. It is not a publicly distributed software product. The tool is used exclusively by our agency team and provides a read-only client portal for our end clients.

Data Access Scope

  • All API calls are made under our agency MCC account (930-696-8254)
  • Client accounts are linked to the MCC via standard Google Ads manager linking
  • We only access accounts that have explicitly granted our MCC management access
  • No data is sold, shared, or transferred to third parties
  • All access tokens are stored encrypted in our database

Data Storage Policy

  • Campaign performance data is synced and cached in our database every hour
  • OAuth access tokens are stored encrypted using AES-256
  • No raw Google Ads data is exposed to end clients — only aggregated metrics
  • Data is retained for 24 months for historical reporting purposes

6. Security Measures

  • All API credentials (OAuth tokens, developer token) stored in encrypted environment variables
  • Server-to-API communication over HTTPS/TLS only
  • Role-based access control — agency users cannot access other clients' data
  • MFA enforced for all agency admin accounts
  • OAuth tokens refreshed automatically before expiry
  • Access tokens revocable at any time from the platform settings
  • Full audit log of all API write operations (create, update, pause campaigns)
  • No client-side exposure of API credentials or raw tokens

7. Policy Compliance

  • All usage is strictly within the Google Ads API Terms of Service and Program Policies
  • API access is used solely for managing ad campaigns on behalf of clients who have explicitly granted our MCC access
  • We do not resell, distribute, or white-label access to the API itself
  • We do not use the API for scraping, competitive intelligence, or unauthorized data collection
  • Privacy Policy published at: https://scaleadsflow.com/privacy-policy.html
